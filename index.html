계보도 자동 생성기

다운라인 데이터 파일과 최상위 회원번호만 입력하면, 후원인(스폰서) 관계를 따라 박스형 계보도를 자동으로 그려줍니다.

1. 데이터
파일을 선택해주세요. 회원번호·회원명·후원인회원번호·활동상태·직급·PPV·DPV·메인레그DPV 열이 포함되어 있어야 합니다.
쉼표(,)로 여러 명을 입력하면 나란히 비교해서 보여줍니다.
2. 검색
0/0
3. 필터
파일을 불러오면 직급 목록이 표시됩니다.
4. 화면 확대/축소
100%
5. 내보내기
엑셀 내보내기는 화면 필터와 무관하게 선택한 최상위 회원(첫 번째)의 전체 하위 조직을 내보냅니다.
요약 통계
조직도를 생성하면 표시됩니다.
박스 구성 (7가지 정보)
DPV (활동 회원)
DPV (탈퇴 회원)
PPV (개인주문 있음)
PPV 없음 / 이름 / 회원번호 / 추천인
직급
DPV차이 (DPV－메인레그DPV)
박스를 클릭하면 그 사람을 최상위로 다시 그립니다. 선 위의 동그라미(●)를 클릭하면 하위 조직을 접거나 펼칩니다.
🗂️

파일과 최상위 회원번호를 입력하세요

왼쪽에서 다운라인 데이터 파일(.xlsx)을 올리고 최상위 회원번호를 입력한 뒤 "조직도 생성" 버튼을 누르면 여기에 계보도가 그려집니다.
