계보도 자동 생성기

다운라인 데이터 파일과 최상위 회원번호만 입력하면, 후원인(스폰서) 관계를 따라 박스형 계보도를 자동으로 그려줍니다.

1. 데이터
파일을 선택해주세요. 회원번호·회원명·후원인회원번호·활동상태·직급·PPV·DPV·메인레그DPV 열이 포함되어 있어야 합니다.
2. 최상위 회원
쉼표(,)로 여러 명을 입력하면 나란히 비교해서 보여줍니다.
2. 검색
0/0
3. 필터
파일을 불러오면 직급 목록이 표시됩니다.
4. 화면 확대/축소
100%
5. 내보내기
엑셀 내보내기는 화면 필터와 무관하게 선택한 최상위 회원(첫 번째)의 전체 하위 조직을 내보냅니다.
요약 통계
조직도를 생성하면 표시됩니다.
박스 구성 (7가지 정보)
DPV (활동 회원)
DPV (탈퇴 회원)
PPV (개인주문 있음)
PPV 없음 / 이름 / 회원번호 / 추천인
직급
DPV차이 (DPV－메인레그DPV)
박스를 클릭하면 그 사람을 최상위로 다시 그립니다. 선 위의 동그라미(●)를 클릭하면 하위 조직을 접거나 펼칩니다.
2. 계산 대상
이 회원을 기준으로 유니레벨/멘토/비즈니스 개발 보너스를 예측합니다.
기본값은 이번 달 실제 달성가능직급입니다. 다른 직급을 선택하면 "만약 이 직급이라면?" 예상치를 볼 수 있습니다.
CV 환산 기준
CV = PPV × 1,550 × 0.7 ÷ 1.1
(사용자 제공 환산식)
참고
이 예측은 업로드하신 다운라인 파일의 이번 달 스냅샷 기준입니다. 전월 대비 변동, 회사 전체 매출(글로벌 풀), 팩 주문 이력 등은 반영되지 않습니다. 자세한 내용은 계산 결과 하단의 "가정 및 한계"를 확인하세요.
